# 로켓소싱

[설치파일 다운로드](https://github.com/kokor64-byte/rocket-sourcing-updates/releases/latest/download/RocketSourcing-Setup.exe)

Windows용 로켓소싱 설치파일과 업데이트를 배포합니다.

## 처음 설치하거나 업데이트 기능이 없는 기존 설치본

1. 위 설치파일을 다운로드합니다.
2. 실행 중인 로켓소싱을 종료하고 설치파일을 실행합니다.
3. 설치를 완료한 뒤 바탕화면의 로켓소싱을 실행합니다.

기존 설치 위치의 수집 자료, 마진 장부, 로그인 정보는 유지됩니다. 다른 컴퓨터로 자료를 옮길 때는 설정·백업에서 전체 백업을 저장하고 복원하세요.

## 이후 업데이트

로켓소싱에서 **설정·백업 → 프로그램 업데이트 → 업데이트**를 누르세요. 최신 파일을 검증하고 프로그램을 교체한 뒤 다시 엽니다. 수집·조회와 편집 중인 내용을 마친 뒤 실행하세요.

## 배포 파일

- `RocketSourcing-Setup.exe`: 설치용
- `RocketSourcing-버전.zip`, `update.json`: 프로그램이 사용하는 업데이트 자료

이 저장소에는 사용자 상품 자료나 로그인 정보를 올리지 않습니다.
